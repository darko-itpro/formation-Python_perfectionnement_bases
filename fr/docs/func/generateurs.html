6  Rappel sur les générateurs

Un générateur est un objet particulier en Python. Vous avez dû voir deux manières de base pour les créer.

6.1 Générateurs avec le mot clef yield

Si une fonction utilise le mot clef yield, elle devient un générateur.

camelot = ["Arthur", "Merlin", "Lancelot",
           "Robin", "Perceval", "Karadoc"]

def upperise(sequence):
    for item in sequence:
        yield item.upper()

print(upperise(camelot))  # <generator object upperise at 0x113f81c40>

Vous pouvez utiliser la structure for pour itérer sur les éléments fournis par le générateur.

for element in upperise(camelot):
    print(element)

6.2 Générateurs avec la syntaxe de Lists Comprehension

Si au lieu des crochets des Lists Comprehension, vous utilisez des parenthèses (ou pas selon le contexte), vous ne créez pas une liste mais un générateur.

print((element.upper() for element in camelot))

Dans cet exemple avec la fonction print(), les parenthèses ne sont pas nécessaires. Elles ont été conservées pour mettre en évidence la structure du générateur.

6.3 D’autres générateurs, mais pourquoi ?

Python propose quelques générateurs comme la fonction range(). Sous Python 2, cette fonction retournait une liste. La fonction xrange() retournait un générateur et correspond à la fonction range() de Python 3. Si vous souhaitez obtenir une liste d’entiers, il suffit de faire list(range()) ce qui est généralement à éviter.

Si Python gère assez bien la mémoire, il y a quelques problèmes avec les listes d’entiers et de réels qui ne sont pas forcément libérées avant la fin du programme.

Vous pouvez vérifier ceci avec le code suivant. Celui-ci nécessite psutil que vous installerez avec pip.

import os
import psutil

process = psutil.Process(os.getpid())

while True:
    l = list(range(1 * 1000 * 1000))
    print(f"Memory usage: {process.memory_info()[0] / float(2 ** 20)} MB")

L’affichage en illustration sera le suivant :

Les différentes versions de Python n’ont pas le même comportement avec ce programme mais le résultat sera toujours une augmentation de la mémoire utilisée. Dans le cas présent, elle se limite à une certaine taille.

De manière générale, favorisez les générateurs pour éviter ce défaut.

6.4 Mais après tout, qu’est-ce qu’un générateur ?

Un générateur est un objet spécial qui permet de manipuler un itérateur sur la fonction. Nous pouvons alors parcourir les valeurs produites par appel à la fonction builtin next() ou par appel à la méthode spéciale __next__().

Dans la pratique, la structure for appelle à chaque itération cette fonction __next__() du générateur.

Lorsque vous créez un générateur avec le mot-clef yield, le générateur arrête l’exécution de la fonction à ce mot clef et attends l’appel à la fonction __next__(). Elle fournit alors la valeur suivant le mot clef et reprends jusqu’au yield et attends à nouveau.

Nous verrons comment créer nos propres itérateurs et itérables dans la partie sur la programmation orientée objet.

6.5 Recevoir avec yield

Le mot-clef yield peut aussi être utilisé par un générateur pour recevoir des données qui lui seront envoyées par la méthode .send(). La syntaxe que vous aurez dans le générateur est de type x = yield.

Un exemple d’illustration d’un générateur recevant et produisant une valeur est le suivant :

def test_gen():
    while True:
1        x = yield
2        yield x * 2

mygen = test_gen()
3next(mygen)
4print(mygen.send(10))
5next(mygen)
print(mygen.send(5))
1
Cette instruction permet au générateur de recevoir une valeur.
2
Suivi du renvois de la valeur.
3
Le premier next() est indispensable pour faire avancer le générateur au premier yield. À défaut, vous aurez une erreur : TypeError: can't send non-None value to a just-started generator.
4
l’envoi de valeur par .send() va provoquer le calcul et le retour du résultat
5
Il est nécessaire d’avancer le générateur.

6.6 La structure yield from

Ajoutée en Python 3.3, la structure yield from permet de simplifier l’appel d’un sous-générateur.

Ainsi, plutôt que d’écrire :

def demo_yield():
    for item in range(10):
        yield item

On écrit :

def demo_yield_from():
    yield from range(10)

Notez que tant que l’action yield from s’exécute, le générateur demo_yield_from est remplacé par le générateur range.
