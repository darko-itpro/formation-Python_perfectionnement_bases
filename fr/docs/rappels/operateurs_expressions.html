3  Opérateurs et expressions

3.1 Opérateurs de comparaison et booléens

3.1.1 Les booléens

Le type bool ne contient que deux valeurs : True et False.

Les opérateurs booléens ne se limitent pas à l’usage de types booléens. D’autres types peuvent être utilisés et certaines de leurs valeurs seront considérées comme fausses (on parle quelquefois de falsy pour éviter la confusion). Ainsi, les collections vides, les nombres nul (0, 0.0…) ou le type None sont considérés comme falsy.

Type FAUX
Bool False
int 0
float 0.0
string “”
tuple ()
list []
dict {}
None Type None

On peut donc directement tester les valeurs sans les convertir en type bool.

knights = []

if knights:
    print("Go for the Grail")
else:
    print("need to hire knights…")

3.1.2 Les opérateurs logiques

Les opérateurs logique sont, par ordre de priorité, or, and et not

La négation not retourne une donnée de type bool. L’opérateur de conjonction and et l’opérateur de disjonction or nécessitent deux expressions à évaluer (soit x et y ces expressions) et sont considérés comme paresseux. Cela signifie que l’expression de droite ne sera évaluée que si nécessaire. De plus, ces opérateurs ne retournent pas de valeur de type booléenne. Ceci s’explique par leur comportement qui est :

La conjonction x and y retournera y si x sinon x.

La disjonction x or y retournera x si x sinon y.

army = []
heroes = ["lancelot", "Perceval"]

1print(f"{heroes or army=}")
print(f"{army or heroes=}")

2print(f"{army and heroes=}")
1
Le retour affiché de cet opérateur sera ['lancelot', 'Perceval']
2
Le retour affiché de cet opérateur sera []

3.1.3 La structure for else

Les blocs des boucles (for ou while) peuvent être suivis d’un bloc else. Ce bloc sera évalué si la sortie de la boucle s’est faite autrement que par un break, autrement dit si la sortie de la boucle a eu lieu normalement après avoir parcouru toutes les itérations.

C’est une structure qui se justifie principalement avec le bloc for et évite l’usage d’un flag. Le choix du mot clef peut prêter à confusion mais il correspond à l’intention qui est la recherche d’un élément où, si il n’a pas été trouvé, nous avons une action à réaliser. La lecture doit être « Je recherche un élément, je parcours tous les éléments de ma séquence. Si je l’ai trouvé, break, sinon…).

camelot = ['Arthur', 'Merlin', 'Lancelot', 'Robin']
wizards = ['Merlin', 'Tim']

for peon in camelot:
    if peon in wizards:
        print("The kingdom has a wizard")
        
else:
    "Sir, you need to find a wizard"

Nous pouvons aussi utiliser un bloc else avec les exceptions. La clause else suit tous les blocs except et permet d’exécuter du code si aucune exception n’a été levée. Si vous l’utilisez, la clause finally doit toujours être la dernière déclarée.

3.2 Le Slicing

Le slicing est un outil très utile en Python. Il permet d’accéder à des slices de séquences ou aux éléments en fonction d’un pas. Mais il peut aussi être utilisé d’autres manières

3.2.1 Affectations

La notation par slice peut permettre de remplacer un nombre d’éléments différent dans une liste.

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
letters = ["a", "b", "c"]

numbers[1:3] = letters
1print(numbers)

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
numbers[1:6] = letters
2print(numbers)
1
Affichera ['one', 'a', 'b', 'c', 'four', 'five', 'six', 'seven']
2
Affichera ['one', 'a', 'b', 'c', 'seven']

3.2.2 Suppression d’éléments

L’instruction del sur un élément d’une liste supprime l’élément. L’instruction del peut être utilisée avec les slices pour supprimer plusieurs éléments

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
del numbers[2]
1print(numbers)

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
del numbers[2:5]
2print(numbers)

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
del numbers[::2]
3print(numbers)
1
Affichera ['one', 'two', 'four', 'five', 'six', 'seven']
2
Affichera [‘one’, ‘two’, ‘six’, ‘seven’]
3
Affichera ['two', 'four', 'six']

3.2.3 Object Slice

Les slices sont aussi un objet en Python. Un objet slice(start, stop, step) peut être passé à la place d’entiers.

numbers = ["one", "two", "three", "four", "five", "six", "seven"]
1my_slice = slice(2, 4)
1
my_slice contient ['three', 'four']

3.3 Opérateur ternaire

Python propose la syntaxe suivante pour l’opérateur ternaire :

valeur_si_vrai if condition else valeur_si_faux

L’opérateur ternaire est à utiliser pour évaluer une valeur en fonction d’une condition. Notez que l’opérateur ternaire retourne une valeur, les parties de gauche (si vrai) ou droite (si faux) doivent donc retourner une valeur.

3.4 Itérer sur plusieurs séquences

La fonction zip() permet d’itérer sur plusieurs séquences. L’objet retourné est un itérateur qui retourne un tuple des éléments des séquences itérées.

Un usage simple peut être le suivant :

camelot = ["Arthur", "Merlin",
           ("Lancelot", "Robin", "Perceval", "Karadoc")]
roles = ["king", "wizard", "knights"]

for role, peon in zip(roles, camelot):
    print(role, peon)

Si les séquences n’ont pas le même nombre d’éléments, l’itération s’arrêtera à la fin de la plus courte.

3.5 Notation par intension

Les Comprehension lists sont un outil très pratique en Python pour transformer ou filtrer des listes. 

Mais cette notation n’est pas limitée aux listes. Nous pouvons par exemple l’utiliser avec des dictionnaires.

Nous pouvons d’ailleurs combiner cette propriété avec la fonction zip() :

print({role:peon for role, peon in zip(roles, camelot)})

3.6 Packing et unpacking

L’unpacking (ou déballage en français) permet d’extraire automatiquement des éléments d’une séquence. Vous l’avez certainement déjà vu avec l’affectation d’éléments d’une liste ou d’un tuple à des variables.

hour, minutes = divmod(75, 60)

Et vous l’avez certainement déjà utilisé lors des itération sur un enumerate().

Dans ce cas, l’unpacking est automatique. Il est cependant possible de le forcer à l’aide du Star Operator *.

Attention, cet opérateur ne s’utilise que dans certains contextes. Et en fonction du contexte, c’est un opérateur de déballage ou d’emballage (packing/unpacking).

3.6.1 Opérateur d’unpacking

Vous pouvez l’utiliser pour déballer une séquence dans un contexte qui attends la séquence ou les éléments de la séquence comme les paramètres d’une fonction.

print("Il est {:02}h{:02}".format(*divmod(75, 60)))

Dans cet exemple, sur les heures obtenus par divmod(), vous n’avez pas besoin de passer par des variables transitoires.

3.6.2 Opérateur de packing

Le star operator peut aussi être utilisé pour emballer des éléments. Il peut être utile lorsqu’on utilise le déballage automatique lors de l’affectation d’une séquence à des variables. Il permet ainsi de récupérer les données excédentaires.

king, wizard, *others = camelot

3.6.3 Inversion du contenu de variables

Vous connaissez certainement l’idiome a, b = b, a qui permet d’inverser le contenu de deux variables.

Dans la pratique, il met en œuvre l’unpacking. En effet, à droite de l’affectation, vous avez la création d’un tuple de deux éléments. En affectant son contenu à deux variables, vous déballez dans la même action le tuple.
