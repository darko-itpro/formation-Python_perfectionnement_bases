8  Properties et descripteurs

8.1 Les descripteurs

Un descripteur est un objet définissant les méthodes __get__(), __set__() ou __delete__() (au moins une). Ils sont la base de beaucoup de fonctionnalités en Python tel que les fonctions, les méthodes, les properties, les méthodes de classe, les méthodes statiques et les références vers les super classes.

8.1.1 Exemple de base

class Answer:
    def __get__(self, obj, objtype=None):
        return 42

Ce descripteur doit être utilisé comme attribut de classe :

class Universe:
    meaning_of_life = Answer()

Ce qui permet un usage :

u = Universe()
u.meaning_of_life

8.1.2 Accéder aux attributs

Les descripteurs sont utilisés pour accéder aux attributs.

class TurtleAccess:
    def __get__(self, obj, objtype=None):
        return obj._turtle_name
        
    def __set__(self, obj, value):
        obj._turtle_name = value.title()
        
class DiscWorld:
1    turtle_name = TurtleAccess()

    def __init__(self, turtle_name:str):
2        self.turtle_name = turtle_name
        
discworld = DiscWorld("a'tuin")
3print(discworld.turtle_name)
1
Création d’une instance du descripteur TurtleAccess
2
Appel au __set__() du descripteur
3
Appel au __get__() du descripteur et affichage de la chaine "A'Tuin".

8.1.3 Plus généralement

Les descripteurs sont des objets, leur définition peut donc avoir un constructeur et des méthodes spécifiques.

8.2 Les properties

8.2.1 Principe général

Une property est un objet créé par la fonction built-in property(). La signature de cette fonction est :

property(fget=None, fset=None, fdel=None, doc=None)

Appeler property() est une manière succincte de construire un descripteur de données en fournissant :

  • Une fonction fget pour les accès object.property
  • Une fonction fset pour les accès object.property = value
  • Une fonction fdel pour les expressions del object.property

8.2.2 Exemple complet

Soit la classe simplifiée :

class Training:
    def __init__(self, title: str, max_seats: int|str = 10):
        self.title = title.upper()
        self.max_seats = int(max_seats)
        self._students = []
        
    def add_student(self, student: Student):
        self._students.append(student)

Nous pouvons définir les fonctions :

def get_students(self):
    return self._students.copy()
    
def set_students(self, students: list):
    self._students[:] = students[:]
    
def del_students(self):
    self._students.clear()

et donc ajouter dans la classe Training :

class Training:
    ...
    
    students = property(fget=get_students, fset=set_students, 
                        fdel=del_students)

Mais chaque paramètre est optionnel donc vous pouvez ne déclarer que ceux qui ont un sens :

class Training:
    ...
    
    students = property(fget=get_students)

Modifier ou supprimer l’attribut students entrainera un AttributError. Ceci permet d’avoir un attribut en lecture seule :

python_t = Training("python", 5)
python_t.add_student(Student("Kevin", "Mitnick"))
python_t.add_student(Student("Elliot", "Alderson"))

1print(python_t.students)
2python_t.students = []
1
Affichage dans la console de [Student Kevin, Mitnick, Student Elliot, Alderson]
2
Lève une exception AttributeError: can't set attribute 'students'

8.2.3 Déclarer une property par décorateur

La déclaration de properties est simplifiée par le décorateur property. Au lieu de définir des fonctions et la variable de classe property(), vous définissez l’accesseur comme une méthode standard mais décorée avec @property.

@property
def students(self):
    return self._students.copy()

Python créera alors l’attribut de classe students avec cette méthode en tant que fget.

Si vous souhaitez ajouter également les fonctions fset et/ou fdel, vous déclarez les méthodes correspondantes mais il faut utiliser un décorateur qui lie ces fonctions à la property créée par l’accesseur. Pour cela, cette property propose 2 fonctions à utiliser en décorateur :

@students.setter
def students(self, students: list):
    self._students[:] = students[:]

@students.deleter
def students(self):
    self._students.clear()

8.2.4 Limite de la syntaxe par décorateurs

Avec la fonction property, vous pouvez créer des properties avec toutes les combinatoires écriture, lecture et suppression. Avec le décorateur, la property sera créé en lecture. Vous ne pouvez donc pas utiliser le décorateur si vous ne voulez pas accéder à la property.

8.2.5 Properties et encapsulation

L’exemple d’usage des properties pour contrôler l’accès à un attribut réel de l’objet est la première étape et l’explication la plus simple. Mais les properties permettent de réellement mettre en œuvre la notion d’encapsulation consistant à masquer l’implémentation : elles permettent d’exposer un état décorrélé de l’implémentation.

Prenons l’exemple du nombre de places de la formation. Elle est créée avec le nombre de places total mais nous pouvons vouloir savoir combien de places il y a de disponibles. Cette nformation est un état donc un attribut mais qui dépends de deux autres états. Il peut donc être évalué à chaque demande par une property :

@property
def available_seats(self):
    return self.max_seats - len(self._students)

Retenez que les properties permettent d’exposer des attributs en masquant l’implémentation réelle. L’utilisateur de l’objet verra un attribut mais vous, vous serez libre de choisir son implémentation ou même la faire évoluer. Considérons en effet que cet objet évolue en intégrant une interaction avec une base de données. La property students accesseur ira chercher les informations en base. Il n’y a alors plus d’attribut students mais avec les properties, l’utilisateur de l’objet n’en a aucune idée.

Ces deux derniers exemples servent à vous illustrer que accesseurs et mutateurs ne sont pas associés à un attribut du même nom. La conception (ou l’évolution) d’une classe doit d’une part définir son interface (tout ce qui est publique) et d’autre part choisir au mieux l’implémentation.
