9  Les classes et méthodes abstraites

La Programmation Orientée Objet possède le concept de classe abstraite. Une classe abstraite est une classe qui ne peut pas être instanciée. Elle possède une implémentation, un squelette de base, mais incomplet et l’objectif est que cette classe soit spécialisée. 

Le schéma UML ci-contre dessous propose un exemple impliquant une classe abstraite dans notre contexte.

Dans notre système, chaque mois, je dois calculer la paye de chaque collaborateur. Pour cela, nous définissons pour la classe Employee une méthode, elle aussi abstraite, calculate_payroll().

Explications : la classe Employee est trop générique pour implanter cette méthode car ce calcul dépends du statut du collaborateur, ici, un salarié payé au mois ou un prestataire payé sur la prestation (un prestataire n’est pas un employé en tant que tel mais on se permettra cette approximation pour l’illustration).

La mtéhode calculate_payroll() n’a donc pas d’implémentation ou une implémentation partielle et est déclarée comme abstraite ce qui entraine le statut de classe abstraite pour Employee.

Python ne gère pas nativement les classes abstraites. Python propose cependant la bibliothèque ABC pour Abstract Base Classes. La raison de son ajout est exposé dans la PEP 3119.

9.1 Exemple de classe abstraite

Vous pouvez déclarer une classe abstraite de la manière suivante.

1class Employee(ABC):
    def __init__(self, first_name: str, last_name: str, id:str):
        self.first_name = first_name
        self.last_name = last_name
        self.id = id

2    @abstractmethod
    def calculate_payroll(self) -> float:
        pass
1
Une classe abstraite hérite de ABC. Elle doit contenir au moins une méthode abstraite
2
Une méthode est déclarée comme abstraite en étant décorée par @absractmethod. Cette méthode peut contenir du code.

Si vous essayez d’instancier cette classe, vous aurez une exception avec un message du type :

TypeError: Can't instantiate abstract class Employee with abstract method calculate_payroll

Vous devrez donc spécialiser cette classe.

9.2 Spécialiser une classe abstraite

Lorsque vous spécialisez une classe abstraite, si vous ne surchargez pas les méthodes abstraites,  vous aurez toujours une classe abstraite.

Pour obtenir une classe concrète, vous devez implémenter toutes les méthodes abstraites comme dans l’exemple de code suivant.

class SalaryEmployee(Employee):

1    def calculate_payroll(self) -> float:
        return self.monthly_salaray
1
La méthode est spécialisée sans être décorée avec @absractmethod ce qui en fait une méthode concrète.

En complément, si la méthode générale contient du code, il est évidemment possible de l’appeler de la manière habituelle.
