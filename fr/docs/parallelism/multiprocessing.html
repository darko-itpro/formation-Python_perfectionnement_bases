15  Introduction au multiprocessing

Le module multiprocessing tire tous les avantages des CPUs. À un haut niveau, il crée de nouvelles instances de l’interpréteur pour fonctionner sur un CPU dédié. Lancer un nouvel interpréter est plus couteux que démarrer un nouveau thread.

Le module multiprocessing a la même interface que le module threading. De base, vous ne pourriez n’avoir que l’import à changer en remplaçant Thread par Process. Une astuce consiste à utiliser un alias pour l’import afin de switcher l’import à loisir.

Notez également qu’avant d’utiliser les processus fils, sous Windows, devez ajouter cette ligne.

from multiprocessing import freeze_support
if __name__ == "__main__":
    freeze_support()

L’explication vient du fait que sous Windows, le fork d’un programme n’est pas possible de la même façon que sous les systèmes Posix. Il est d’usage d’ajouter systématiquement cette ligne qui sera sans effet sous Linux/MacOS.

Cependant, utiliser plusieurs process revient à forker votre programme, les données ne sont alors plus partagées. Ainsi, à chaque nouveau process, vous aurez un nouveau programme avec une copie des données.

Pour manipuler les même données il faut les allouer à une mémoire partagée.

15.1 Utilisation de la mémoire partagée

Utiliser la mémoire partagée comporte quelques limites.

Les types de Python (dictionnaires, listes, …) ne sont pas utilisables dans la mémoire partagée. Seuls les types du module ctypes le sont. Il s’agit des types natifs du langage C. Le module multiprocessing permet d’allouer ces données via 4 classes :

  • RawValue, donnée brute, sans verrou associé data = RawValue(ctypes.c_long, 0)
  • RawArray, tableau brut, sans verrou associé 
  • Value, valeur ayant un verrou qui lui est associé data = Value(c_types.c_long, 0, lock=True)
  • Array, tableau ayant un verrou associé. 

Une valeur issue d’une variable de type Value/RawValue ne peut pas être manipulée avec une variable ordinaire Python. Il faut utiliser la propriété .value comme dans l’exemple suivant :

1In [17]: n = RawValue('d', 10)

In [18]: n.value
Out[18]: 10.0

In [19]: n.value += 10

In [20]: n.value
Out[20]: 20.0
1
l’argument 'd' représente un c_double. Vous pouvez également utiliser 'i' pour les c_int et 'h' pour les c_short.

Le verrou des objets de type Value/Array s’utilise via la méthode get_lock() et sont context safe.

In [10]: counter = Value("i", 0)

In [11]: with counter.get_lock():
    ...:     counter.value += 1
