## Information sur les logs

Pour les exercices, des fonctions vous sont proposées. Ces fonctions sont dans l'arborescence du
répertoire `src`. Ces fonctions loguent des informations et pour cela utilisent les arborescences
propres à la plateforme grâce à `platformdirs`. Leur localisation dépends donc de votre système.
Consultez [la page de documentation dédiée aux répertoires](https://platformdirs.readthedocs.io/en/latest/platforms.html).
